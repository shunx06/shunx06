# reels — Instagram (@dr.shun.fitness) 運用バンク

「医師 × フィジーク × HYROX挑戦中」を伸ばすための、台本・撮影リスト・キャプションのストック。
**撮影は最小・AIとツールで量産**を回すための素材置き場です。

## コンセプト（ブレさせない軸）
- ポジション：**消化器内科医なのに、本人がHYROX/フィジークに挑戦している当事者**（日本ではほぼ空白＝最大の武器）
- トーン：ゆるく真面目。一人称は「僕」。
- 立ち位置：診断・治療ではなく「一般的な情報提供」。誇張・他院比較はしない。

## 運用パイプライン（半自動）
```
① 台本＋ショットリスト（このリポジトリ / AIが量産）
      ↓
② まとめ撮り（週1・shot-list 通りに撮るだけ）← 君の作業はここだけ
      ↓
③ 長尺→複数ショート＋自動字幕（OpusClip / CapCut / Vrew）
      ↓
④ キャプション＋ハッシュタグ付与（caption-and-hashtags.md から）
      ↓
⑤ 予約投稿（19–21時）
```

## 投稿ルール（2026年の勝ち筋）
- **量より質**：週3〜5本を安定供給（乱造は逆効果）
- **1行目（フック）が命**：最初の1秒で「結論・数字・意外性」
- **型を固定**：フック → 本題 → CTA
- **音源**：↗マーク付きのトレンド音を優先
- **投稿時間**：19–21時
- **タグ付け**：HYROX回は `@hyroxjapan` `@hyroxworld`
- **CTAは1つ**：基本は「保存＆フォロー」

  - `04-wallball.md` … HYROX種目のコツ（ハウツー）
  - `05-doctor-why.md` … 医師目線の解説
