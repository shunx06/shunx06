# プロフィール最適化 — @dr.shun.fitness

リールで届いた新規（#002は閲覧者の約9割がフォロワー外）を**フォローに変換**するための入口。
bioの1〜2行目で「誰で・何に挑戦してるか」を一目で伝えるのが狙い。

## 現状のbio（改善前）
```
🏥筋肉医局/横浜/消化器病専門医/内視鏡専門医/内科専門医
💪マッチョな消化器内科医を目指すアカウント
🏋 2026/3/8 APF FIRST IMPACT 出場
```
**課題**
- 「HYROX」の文字が無い → HYROXリールから来た人に刺さらない
- APF出場日（2026/3/8）が過去のまま＝更新されていない印象
- "何が見られるアカウントか"（提供価値）が弱い

## 推奨bio（改善後・コピペ用）
```
🩺消化器内科医｜消化器病・内視鏡・内科専門医＠横浜
🏋️‍♂️フィジーク × HYROX 挑戦中🔥
📈「医学的に正しい体づくり」減量・トレ・腸活を発信
👇最新の挑戦はリール＆ハイライトへ
```

**変更点**
1. **2行目にHYROXを明示**（挑戦中🔥）→ リール流入と一致、興味が途切れない
2. 1行目は専門医の肩書きを残す（＝他のフィットネス垢に無い信頼＝最大の差別化）
3. 3行目で「何が得られるか」を宣言 → フォローの理由になる
4. 過去日付を削除し、常に古びない表現に
