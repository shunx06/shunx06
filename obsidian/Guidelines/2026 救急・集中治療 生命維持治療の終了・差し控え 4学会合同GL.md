# 生命維持治療の終了／差し控えに関する4学会合同GL（2026, 本編）

> [!summary] 一言で
> 「終末期」の定義で線を引く2014年3学会GLから、**定義をやめて「プロセス（多職種の臨床倫理的検討＋SDM）」を示す**GLに転換。緩和ケアを必須要素として格上げし、TLT・臓器提供・身寄りなし患者・記録項目を明文化。

## 基本情報
- 編集: 日本集中治療医学会／日本救急医学会／日本循環器学会／**日本緩和医療学会（新規参加）**
- 発行: 令和8年（2026年）9月
- 構成: **本編**＋**緩和ケア別編**（各論）＋**Q&A集**（運用上必読とされる）
- 作成法: 多職種委員による**修正デルファイ法**（9段階Likert、**7–9点が70%以上で合意**）。3ラウンドで全項目合意 → パブコメ（2026/2–5）→ 大意不変の修正のみメール審議で確定
- 対象: 疾患・診断名を問わず、救急搬送／ICU緊急入室など**急性期病院で治療の意思決定を行うすべての患者**
- 準拠: 厚労省「人生の最終段階における医療・ケアの決定プロセスに関するガイドライン」（2018）

## 旧GL（2014, 3学会）からの主な変更点

| 項目 | 旧GL（2014） | 新GL（2026） |
|---|---|---|
| 作成学会 | 集中治療・救急・循環器の3学会 | ＋**日本緩和医療学会**の4学会 |
| 「終末期」 | 「適切な治療を尽くしても救命の見込みがないと判断される時期」と定義 | **あえて定義しない**。「生命維持治療の終了／差し控えが考慮される患者」を対象に、判断の**プロセス**を提示 |
| 判断の枠組み | 終末期に該当するかの判断が起点 | ①**多職種の臨床倫理的検討**（4観点）＋②**患者・家族等とのSDM** の2本柱 |
| 意思決定手順 | — | 厚労省プロセスGLに**明示的に準拠** |
| 緩和ケア | 方針決定後の「緩和的措置」に触れるのみで**具体的記述なし** | 総論を本編に、各論を**緩和ケア別編**に。**早期からの基本的緩和ケア**を必須とし、「**適切な緩和ケアを提供できない状態で終了／差し控えを行うべきではない**」 |
| 対応の選択肢 | 維持（新規差し控え）／減量／終了／条件付き選択 ※ | 差し控え（不開始含む）／終了（症状緩和のみ）／**一部終了・減弱**／**TLT（期限付き治療試行）** |
| 臨床倫理コンサルテーション | — | 役割・構成・メンバーのトレーニング要件を明記。**最終決定は原則として医療・ケアチームと患者・家族等** |
| 身寄りなし・身元不詳 | — | 独立項目として追加（厚労省「身寄りがない人…」GLも参照） |
| 臓器提供 | — | 脳死下提供は終了／差し控えの意思決定と**切り離せない**ため同プロセスで情報提供。心停止後提供は終了／差し控えの意思決定**後**に検討 |
| 用語定義 | — | 注釈で「生命維持治療」「治療・ケアのゴール」「プライマリ・チーム」「臨床倫理コンサルテーションチーム／委員会」を定義 |
| 作成方法 | — | 修正デルファイ法＋パブコメ（ACCORD準拠） |

> [!warning] ※旧GLの欄について
> 「終末期」の定義文と「緩和的措置に具体的記述がなかった」点は**新GL本文の記載**に基づく。旧GLの選択肢（維持／減量／終了／条件付き）や終末期の4類型（不可逆的全脳機能不全、複数臓器の不可逆的機能不全で代替手段なし、追加治療なく近日中の死亡が予測、回復不能な疾病の末期）は**記憶ベース**のため、使う前に原典（[jsicm.org 2014 PDF](https://www.jsicm.org/pdf/1guidelines1410.pdf)）で確認すること。

## 要点

### I-1. 判断のプロセス
- 起点: 治療が大きな苦痛を伴うのに、**患者が望む結果につながらない**と考えられる時 → 「治療・ケアのゴール」を再検討し、その選択肢として終了／差し控えを考慮
- **(1) 医療・ケアチームによる臨床倫理的検討**
  - 関わる全診療科・多職種＋**かかりつけ医・在宅医療スタッフ**も参加
  - 医師主導になりがちだった点を是正 → **全職種に公平な発言機会と心理的安全性**
  - 4観点を網羅: **医学的側面／患者の意向／QOL／周囲の状況**（Jonsenの4分割法、臨床倫理検討シート等）
- **(2) SDM**（厚労省プロセスGL準拠）
  1. 意思確認可 → 本人の意思を尊重（意思決定能力を専門的に評価）。能力喪失後もACPが現状に適用可能なら尊重
  2. 確認不可だが推定可 → 推定意思を尊重（ACPは状況が想定と違っても推定根拠になり得る）
  3. 推定も不可 → 家族等と「患者にとっての最善」を話し合う。状況変化に応じて**繰り返す**
  4. 家族等と接触不能・身寄りなし → 年齢・外見の偏見を排し、チーム／倫理委員会が**公正・透明な手続き**で判断
  - SDMのための**コミュニケーションスキルトレーニングを推奨**（SCCM Family-Centered Care GL 2024を引用）
- **(3) 臨床倫理コンサルテーション**: チーム内で決められない、患者・家族等と合意できない、家族内で意見が割れる、意思不明で家族なし、などの場合に活用。プロセスの妥当性を判断・支援する組織であり、**決定主体ではない**

### I-2. 生命維持治療への対応
1. **差し控え（不開始含む）**: 症状緩和以外の新規治療・増強はしない。装置設定・昇圧薬は減弱できればするが増強しない。検査・モニターは最小限。**CPRは行わない**
2. **終了**
   - a. 症状緩和のみ: 鎮痛・鎮静は継続・調整。人工呼吸器・補助循環、**ペースメーカー／ICDの除細動機能**の停止・取り外しを検討。血液浄化・昇圧薬・血液製剤・抗菌薬・輸液・**人工栄養・水分補給**の終了も検討
   - b. 一部のみ終了・減弱: 各治療ごとに個別に検討
   - 施設プロトコール策定を推奨。短時間で心停止に至り得るため**家族の立会い**も検討。病状・意向が変われば柔軟に再検討
3. **TLT（time-limited trial）**: 意見の相違や予後不明確な場合に、合意のうえ**期間を決めて特定の治療を試行**（例: 7日間の人工呼吸管理で臓器機能回復・合併症を評価）。離脱困難・許容できない状態・苦痛が受け入れられない場合は終了を検討。一方で侵襲期間の延長による「**死のプロセスの質**」低下のデメリットにも配慮

### I-2-2). 緩和ケア
- WHO定義に基づき、終了／差し控えが検討される患者は**緩和ケアが必要不可欠**
- まず**プライマリ・チームによる基本的緩和ケア**（症状緩和・意思決定支援・心理社会的支援）を**早期から**。困難例は緩和ケア専門家と連携
- 終了／差し控え**後**に緩和ケアを導入するのでは遅い
- 具体的な薬物・手順は「**緩和ケア別編**」参照

### II. 医療・ケアチームの役割
- 予後不良を告げられた家族等への情報提供・信頼関係維持、**悲嘆（グリーフ）の表出支援**
- プライマリ・チーム×緩和ケアチームの協働、人材確保・多職種連携・早期介入の仕組み作り

### III. 診療記録に記載すべき事項
意思決定プロセスは経緯を含め**すべて記録**（後の検証に耐える記載）。

1. **医学的検討とその説明**: 説明対象者と範囲／説明内容／理解・受容の状況／同席した医療・ケア従事者
2. **患者の意思**: 本人の意思 or ACP等の事前の意思とその状況／なければ家族等による推定意思とその根拠
3. **終了／差し控え検討時**: 患者の意思・ACP／推定意思と根拠／家族等の意向／**考慮する時期であることとその根拠**／最善のゴールの検討内容／**検討に加わった全メンバー**

## 注釈（定義）
- **生命維持治療**: 生命維持に必要とみなす治療。装置に限らず、昇圧薬・ペースメーカー・人工栄養／水分補給・血液浄化・輸血・輸液等も**状況によって**生命維持治療となり得る
- **治療・ケアのゴール**: 患者の生き方・価値観・優先順位に基づく方針の指針（例:「退院して社会復帰」「残りの時間を苦痛なく」）
- **臨床倫理委員会**: 助言・調停・教育を行うが最終決定は原則チームと患者・家族等。適切なプロセスを踏んだ決定であれば、訴追時に**チームを守る役割**がある

## 自分用メモ（消化器内科の文脈）
- 消化管出血・重症膵炎・胆管炎などでICU管理となった患者の方針決定にも**疾患を問わず適用**される
- 「終末期か否か」ではなく、**ゴールの再設定 → 多職種検討 → SDM → 記録**の流れで考える
- TLTは家族との意見相違時の実務的な選択肢。期間・評価項目・終了条件を事前に合意し記録する
