# 切除不能・再発大腸癌 レジメン推奨支援アプリ

患者プロファイルを入力すると、**一次治療の推奨レジメンと根拠**、**後続ラインの治療戦略**、
**治療開始前・治療中に必要な検査**を提示する、医療者向けの意思決定支援 Web アプリです。

## 使い方

ビルド不要・依存パッケージなしの静的アプリです。

```
crc-regimen-app/index.html
```

を Web ブラウザで開くだけで動作します（サーバー起動も可）。

1. 左のフォームに患者プロファイル（PS・臓器機能・バイオマーカー・原発部位・治療目標・治療歴）を入力
2. 「推奨を表示」を押す
3. 一次治療の推奨（第一推奨＋代替案とそれぞれの根拠）、後続ライン、必要検査が右に表示されます
4. 「印刷 / PDF保存」でカンファレンス資料として出力できます

## 判断ロジックの骨格

大腸癌研究会「大腸癌治療ガイドライン 医師用 2024年版」の薬物療法アルゴリズムを基本に、以下の順で分岐します。

1. **PS 3–4** → BSC / 緩和ケア中心（可逆要因があれば再評価）
2. **MSI-H / dMMR** → 免疫チェックポイント阻害薬（一次治療、KEYNOTE-177）
3. **MSS / pMMR** → 全身状態で治療強度を決定したうえで、殺細胞性ダブレット（またはトリプレット／単剤）＋分子標的
   - **抗EGFR vs 抗VEGF**: RAS/BRAF 野生型かつ**左側**原発 → 抗EGFR、**右側**や RAS/BRAF 変異 → ベバシズマブ
   - **コンバージョン狙い**（PS良好）→ FOLFOXIRI＋ベバシズマブを軸
   - **BRAF V600E** → 予後不良を踏まえ強力初期治療、後方ラインで BRAF 標的療法

後続ラインは、一次で用いた骨格・分子標的、およびバイオマーカー（BRAF V600E・HER2・KRAS G12C・MSI）に応じて、
二次・三次・サルベージ・がん遺伝子パネル（CGP）まで提示します。

## ファイル構成

| ファイル | 役割 |
|---|---|
| `index.html` | 画面・入力フォーム |
| `styles.css` | スタイル |
| `data.js` | レジメン・検査・主要臨床試験のデータベース |
| `engine.js` | 推奨ロジック（`recommend(profile)`） |
| `app.js` | フォーム入力の読み取りと結果描画 |
